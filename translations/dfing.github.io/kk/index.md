Локализацияны орнатушы DF 50.10 және одан кейінгі нұсқаларын, соның ішінде 51, 52 және 53 нұсқаларын қолдайды.
Steam, itch.io. Windows және Linux платформаларына арналған классикалық нұсқаларға қолдау көрсетіледі.

Аударманы қалай орнату керек туралы қысқа нұсқаулық:

- Орнатқышты жүктеп алып, бумадан шығарыңыз да, `dfint-installer` файлын ашыңыз.
- Ойынның орындалатын файлын (`Dwarf Fortress.exe` немесе `dwarfort`) таңдаңыз («Ашу» дегенді басыңыз). Немесе `dfint-installer` файлын ойын қалтасына салыңыз, сонда орнатқыш ойынның орындалатын файлын өзі табады.
- Аударма тілін таңдап, «Жаңарту» дегенді басыңыз.
- Ойынды қосыңыз.
- Ойынның жаңа нұсқасының аудармасын немесе конфигурациясын жаңарту үшін орнатушыны қайта іске қосыңыз (ойын жабық кезде), содан кейін «Жаңарту» дегенді басыңыз.

Орнатушыға қатысты мәселелер туындаса (мысалы, Windows 7 немесе 8 жүйесін пайдаланып жатсаңыз), [package-builder](https://dfint-package-build.streamlit.app){:target="_blank"} қолданбасын пайдалануға болады.
